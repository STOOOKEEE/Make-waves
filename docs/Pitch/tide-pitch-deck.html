Funded, with a soulbound proof of first trade and results paid on the ledger. A CEX demo ends in a deposit to the CEX. TradingView ends in a broker referral. Neither can end on a neutral ledger.

Unfair advantage 2

The evaluation engine already runs

One rule book for humans and AI agents, enforced by the server: max capital, daily loss, trades, leverage, kill switch. Funded-trader firms sell opacity; we sell a public audit trail.

Unfair advantage 3

Zero to the native DEX, no exchange in between

No KYC, no purchase, no swap fee, every transaction tagged. Built on primitives that have been on mainnet for years. The ecosystem funds this; no exchange will.

The code is copyable. The corpus is not: track records on the ledger, outcome data from lesson one to funded account, cohorts and classrooms. It compounds with every learner.
