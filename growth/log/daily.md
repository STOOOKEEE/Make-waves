# Daily runsheet

The whole loop on one page. Open this each day. ~60–90 min. Everything links to the file that
explains *why* — this is just the *what*, in order.

> **First: what's the date and weekday?** Confirm it, don't infer it — a day-specific joke on the wrong
> day is dead on arrival (`learnings.md`, 2026-07-21). Today's rhythm slot: see the table in
> `context/04-content-engine.md`.

---

## 1 · Listen (5 min)
- [ ] Read our own replies + quote-tweets from the last 24h. **The comments are the brief** — the best
      post today is often a reaction to what someone said back. (`context/04-content-engine.md`)
- [ ] Skim `posted.md`. Are you about to repeat a joke or a shape from this week? If yes, don't.

## 2 · Reply — the growth engine (30–40 min, the bulk of the day)
- [ ] Pull up the target list (`targets.md`). Mix reach (Tier A) and graph (Tier B).
- [ ] **10–30 replies**, spread across 2–3 sittings — never batched. This number is the hard ceiling
      (`guardrails.md` §3), not a target to beat.
- [ ] For each: **read the existing replies first, then say what nobody said.** The obvious joke is
      already there fifteen times and scores zero. Usually the win is an observation, not a punchline.
      (`replies.md` §4)
- [ ] Second person, in voice, stands alone without the parent. No link, no pitch, no @-pile.
- [ ] Gate every one: *would I upvote this if a stranger wrote it?* No → don't send.
- [ ] Beginner asking a real question → answer it plainly and warmly. That's the reply that converts.
- [ ] Distress + real loss → **say nothing from this handle.** (`context/02-voice.md` hard limits)

## 3 · News loop (~10 min)
- [ ] What's crypto/markets twitter actually arguing about right now?
- [ ] Do we have an angle nobody else has? Usually: "from inside a game where none of it is real."
      **No angle → skip.** A generic take is worse than silence. (`newsjacking.md`)
- [ ] Real losses in the story → no dunking. Empathy or nothing.

## 4 · Post (15 min) — 1 to 3, from `context/04-content-engine.md`
Pick from the **executable** series (the other four need data we don't have — see `data-access.md`):
Explain It Badly · Fake Money Real Pain · Trading-is-absurd · Which One Are You · Ask The Void (1×/wk)
· The Invitation (1×/wk).

Before writing, check the two quotas that fix the account's real problem:
- [ ] **Is at least one post anchored to *today*?** Timeless = brand. If nothing's anchored, you're
      posting filler.
- [ ] **Does this week have an enemy post?** Name a *genre* (signal groups, courses, 4-hour videos,
      bots-only arenas) — never a person. Agreeable posts die.
- [ ] Short. Second person. One idea. Don't land the plane — leave the last thought to the reader.
- [ ] Run the gate (`context/02-voice.md`): would-you-send-this-to-a-friend first, then late / costume
      / landing-page / stranger / facts / villain.
- [ ] ~1 post in 5 is warm, not funny. If the last ten were all jokes, make this one warm.

## 5 · Log (2 min)
- [ ] Draft went in `queue.md` as `PROPOSED`. **Only Eli flips it to `APPROVED`. Nothing ships
      without that.**
- [ ] Posted? Move the block to `posted.md` with the date and the **URL** (grab it at post time — it's
      a pain to backfill).
- [ ] Learned something? One line in `learnings.md`. If it's a real rule, it graduates into `context/`.

## The three things that actually decide whether this works

Not daily tasks — the levers above the daily grind, in order of impact:

1. **Wire up live product data** (`data-access.md`). Until then the account posts *about trading in
   general*; with it, the account posts *what only it can see* — a bot losing to a guy who buys
   whatever's green. This is the difference between "well-written" and "followed." Needs the admin
   token + one small route. **The single highest-impact change available.**
2. **Keep the target list alive** (`targets.md`). Verify handles, re-check monthly. A dead list feels
   done and isn't.
3. **Consistency beats brilliance.** `[STUDY]` Skipping weeks actively hurts; a mediocre week still
   moves the number. The account dies from *stopping*, not from a bad post. (`context/07-growth-system.md` §8)

---

## Realistic expectations (so nobody quits in week 2)

- **90 days → 500–2,000 followers.** Not 10,000. Anyone promising more is selling something.
- **Near-zero growth for the first 2–3 weeks.** This is normal, not failure. It's where people quit.
- Measure **replies sent** and **profile visits**, not follower count. (`context/07-growth-system.md` §6)
